# Jhon Mix – Portfolio Landing Page

A complete, responsive, dependency-free portfolio site for Jhon Mix (Creative Developer & Designer).

## Features

- Sticky responsive navigation with hamburger menu on mobile
- Premium hero section with animated gradient background
- Services grid with hover effects
- Portfolio section with image overlay on hover
- Testimonials carousel with auto-advance and manual controls
- About section with stats and skill tags
- Contact CTA with direct email link
- Footer with social links, copyright, and back-to-top
- Fully responsive (375px to large desktop)
- No external dependencies – pure HTML, CSS, JS

## Usage

Open `index.html` in any modern browser. No build tools, npm, or installation required.

## Deployment

The site is fully static. Deploy by uploading the four files (`index.html`, `styles.css`, `script.js`, `README.md`) to any static host (GitHub Pages, Netlify, Vercel, etc.).
